02 / YOUR CONTROL

03 / TWO WAYS

START IN FOUR STEPS

把重复的事，
简单地做完。

支持 Tampermonkey / Violentmonkey 等油猴脚本管理器。

  1. 安装脚本

    先安装脚本管理器，再点击本页“安装简历轻填”。

  2. 建立自己的资料

    在“资料 → AI知识库”上传文件，选择字段导入或知识提纯；也可以手动填写。

  3. 点击网页字段

    核对模块和具体经历，确认推荐内容。需要时锁定当前具体段。

  4. 写入并核对

    工具检查网页是否保留内容。投递前，仍由你核对并提交。

使用前，你需要知道

AI 功能需要配置自己的 API。操作文档时，会向所选接口发送经过敏感号码过滤的文字。字段导入保留已有值，列出冲突，并展示原文依据。扫描版 PDF 需要先做 OCR；不同网站控件的实际回显仍需核对。
