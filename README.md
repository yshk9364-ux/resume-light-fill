# 简历轻填 · 开源版

一个本机资料库 + 字段级写入的油猴脚本。把重复填写的简历资料整理一次，在不同招聘页面按字段复用。

公开版本以空白资料启动，不包含作者的简历、联系方式、个人素材或使用记录。所有功能免费，采用 MIT 许可证。

在线主页：<https://yshk9364-ux.github.io/resume-light-fill/> ｜ 直接安装：[简历轻填.user.js](https://raw.githubusercontent.com/yshk9364-ux/resume-light-fill/main/docs/download/%E7%AE%80%E5%8E%86%E8%BD%BB%E5%A1%AB.user.js)

## 安装与使用

1. 安装 Tampermonkey / Violentmonkey 等脚本管理器。
2. 打开 `userscript/dist/简历轻填.user.js`，在 GitHub 点击 Raw；或下载项目后，把脚本导入脚本管理器。
3. 打开招聘表单，点击右下角助手的“资料”，手动建立自己的资料或上传文档。
4. 点击网页字段，核对内容后写入。工具会读回检查，最后由你核对并投递。

## 核心功能

- 资料按教育、工作、校园、项目、荣誉、家庭等模块管理。
- 手选具体经历后锁定识别范围，避免跨段串用。
- 日期控件选择；薪资和年限转换先预览；区间可以选择取值方式。
- 确认新字段后，写入成功即保存，后续按名称 / 别名匹配。
- PDF / Word / Markdown / 文本提供两个独立入口：**识别并存入字段库**、**仅作为 AI 提纯知识库**。
- 字段导入要求原文依据，保留已有值与锁定字段，列出冲突；多段经历分别导入。
- AI 提纯知识与原文可查看、编辑、删除；文字可跨招聘网站检索，随备份导出。

AI 功能需要在设置中填写自己的 API。未配置 AI 时，文档可先提取明确标注的姓名、手机、邮箱。文本型 PDF 可直接读取；扫描 PDF 请先 OCR。不同招聘网站的控件、事件和保存行为仍需实际核对。

## 支持项目

在助手点击“支持”，或打开 [项目介绍与赞助页面](https://yshk9364-ux.github.io/resume-light-fill/#support)（仓库内副本：[docs/index.html](docs/index.html)）。微信支付和支付宝分别标注，金额为自愿建议，需要在支付应用内自行输入。

公开脚本累计首次使用超过 30 分钟、成功写入至少 10 次后才可能提醒，自动提醒最多每 7 天一次。可以选择“今日不再提醒”“以后不再提醒”“已支持”。不会验证支付状态，不会限制免费功能。

## 开发

```sh
npm ci
npm run build:userscript
npm test
```

修改 `userscript/src/`；引擎代码位于 `extension/core/`，通过构建脚本生成。建议优先使用油猴版本；扩展壳保留基础表单能力。

`docs/` 是无后端静态页面，可以部署到 GitHub Pages。QR 图片只截取授权提供的二维码区域，保留原始模块和中心图案。
